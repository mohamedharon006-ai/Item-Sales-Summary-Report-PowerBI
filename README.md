# Item Sales Summary Report | Power BI

## 📊 Project Overview

This project is an interactive sales analysis dashboard developed using Microsoft Power BI as part of my Data Analytics learning journey.

The report provides insights into sales performance, profitability, product trends, and business metrics through interactive visualizations and reports.

## 🎯 Project Objectives

- Analyze overall sales performance and trends.
- Evaluate profitability and business costs.
- Explore product performance and sales quantities.
- Analyze sales across different cities and states.
- Present key business metrics through interactive dashboards.

## 📈 Dashboard Pages

- **Sales:** Explore sales performance, quantities, and sales trends.
- **Profit:** Analyze profitability and related business metrics.
- **Details:** Examine detailed sales information, including products and geographical data.
- **Report:** Present business data through visual reports and insights.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Sales Data Analysis

## 💡 Key Learnings

- Building interactive dashboards and reports.
- Transforming sales data into meaningful visual insights.
- Analyzing business performance using data visualization.
- Presenting data to support data-driven decision-making.
